
# Crawling and Scraping Study

## 1. About This Project

This project is a simple code that collects information about pruducts in https://www.coupang.com and news from https://infostock.co.kr. I wrote this to study crawling and scraping.

## 2. Features

- Feature 1: Collects different informations about a certain product in Coupang

## 3. Technologies Used

- Language: Python, HTML
- Libraries / Frameworks: selenium, webdriver_manager, bs4, pandas 

## 4. How to Run

1. Download or clone this repository.
2. Install the required libraries.
3. Run the main program.

## 5. What I Learned

- I learned how to crawl and scrap websites using the libraries above.
- I improved my understanding of how websites are composed.
